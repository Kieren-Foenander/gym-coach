# Exercise demonstrations

`trainer.py` builds a trainer in Blender, animates an exercise, and opens his skin over the muscles it works so their fibres show. `render.sh` runs it and encodes the result for the app.

```sh
tools/blender/render.sh dumbbell-curl            # writes public/exercises/dumbbell-curl.mp4 and .webp
tools/blender/render.sh dumbbell-curl --muscles  # the same with the skin off everywhere, as dumbbell-curl-muscles
tools/blender/render.sh squat                  # front three-quarter squat
tools/blender/render.sh squat --rear           # rear three-quarter squat, as squat-rear
tools/blender/render.sh squat --rear --muscles # rear anatomy view, as squat-rear-muscles
tools/blender/render.sh deadlift              # conventional deadlift from the floor
tools/blender/render.sh deadlift --rear        # rear cutaway
tools/blender/render.sh deadlift --muscles     # front anatomy view
```

## How the trainer is made

He has two layers.

- **Anatomy**: the muscles, tendons and bones of the [Z-Anatomy](https://www.z-anatomy.com/) atlas, used exactly as the atlas shapes them. `atlas.py` loads them, groups them into training muscle groups by name, and works out each muscle's fibre direction.
- **Skin**: a man generated by MPFB (the MakeHuman add-on), with textured skin, hair and trainers. He is posed as the atlas figure stands and then warped to wrap round the anatomy, skeleton and all. The anatomy takes its skinning from the skin over it, so both layers move together.

An exercise names its primary and secondary muscle groups. The skin and shorts open over those, and they glow, the primary ones more. The shorts inherit the skin's reveal mask and rig weights, so the glutes and upper thighs remain visible during the squat. The head, hands and feet retain their skin.

Rear views rotate the lighting behind the figure as well, keeping muscle detail visible. `TRAINER_ANGLE` can set a custom camera angle in degrees (0 is front, 90 is side, 180 is back).

Skinning transfer searches only compatible skin on the same side and limb. This is especially important between the thighs: the closest surface can belong to the opposite leg. Shared pelvis influences remain available; opposite-leg influences never do.

Run the binding regression checks with:

```sh
blender -b --python-exit-code 1 --python tools/blender/test_bind.py
```

The deadlift uses a narrower stance, a double-overhand grip and 45 cm plates. Its bar follows a vertical path; the trunk is positioned from the actual straight-arm grip, and the legs solve back to fixed ankles. The loop includes a standing pause and a controlled return to the floor.

After a still render, check the saved deadlift scene with:

```sh
blender -b /path/to/deadlift.blend --python-exit-code 1 --python tools/blender/check_deadlift.py
```

This checks foot drift, straight elbows, hand contact, grip width, bar travel, floor contact, loop closure and anatomy bound to both legs.

## Setup

1. Blender 5.2 with the MPFB extension:

   ```sh
   blender --online-mode --command extension sync
   blender --online-mode --command extension install mpfb -e
   ```

2. The MakeHuman base assets, in MPFB's user data folder `~/.config/blender/5.2/extensions/.user/blender_org/mpfb/data`, keeping the folder names:

   - From `http://download.tuxfamily.org/makehuman/assets/1.1/base/`: `skins/young_caucasian_male`, `skins/textures`, `eyebrows`, `eyelashes`, `hair/short02`, `clothes/shoes05`, and `eyes/materials`.
   - From the `makehuman` repository on GitHub, `makehuman/data/eyes/high-poly` into `eyes/high-poly`, and `materials/brown.mhmat` with `brown_eye.png` into `eyes/materials`.

3. The atlas, as `~/.local/share/gym-trainer/z-anatomy/Startup.blend`. It is `Z-Anatomy/Startup.blend` inside `Z-Anatomy.zip` from https://github.com/Z-Anatomy/Models-of-human-anatomy. The first run lists its contents into `index.json` beside it, which takes a minute.

4. `ffmpeg`, for encoding.

## Adding an exercise

Write a function in `trainer.py` that poses the skeleton frame by frame and calls `paint` with its muscle groups, and add it to `EXERCISES`. The groups are the names in `GROUP_RULES` in `atlas.py`. Then add the exercise to `src/domain/demos.ts` so the app shows it.

`blender -b --python tools/blender/trainer.py -- <exercise> <folder> --still` renders three stills, which is the quick way to check a pose. Each run rebuilds the trainer, which takes about two minutes.
